# outbid.lol clone

A fan-made, front-end-only clone of [outbid.lol](https://outbid.lol) — a pay-to-rank public leaderboard.

Not affiliated with the original site. No real payments — bids are simulated client-side and persisted to `localStorage`.

## Run locally

```
python3 -m http.server 8000
```

Open http://localhost:8000
